# 📧 QQ邮箱授权码获取教程

## 问题说明

如果遇到 `535 Error: authentication failed` 错误，说明SMTP认证失败。QQ邮箱必须使用**授权码**而不是登录密码。

## 获取QQ邮箱授权码步骤

### 步骤1: 登录QQ邮箱

1. 打开浏览器，访问 https://mail.qq.com
2. 使用QQ号和密码登录

### 步骤2: 进入账户设置

1. 登录后，点击右上角的**"设置"**
2. 在左侧菜单中，点击**"账户"**

### 步骤3: 开启SMTP服务

1. 向下滚动，找到 **"POP3/IMAP/SMTP/Exchange/CardDAV/CalDAV服务"** 部分
2. 找到 **"POP3/SMTP服务"** 选项
3. 点击 **"开启"** 按钮

### 步骤4: 验证身份

1. 系统会要求您发送短信验证
2. 按照提示发送短信到指定号码
3. 发送成功后，点击 **"我已发送"**

### 步骤5: 获取授权码

1. 验证成功后，系统会显示一个**16位的授权码**
2. **立即复制**这个授权码（只显示一次！）
3. 格式类似：`abcdefghijklmnop`（16位字符）

### 步骤6: 配置到项目

将授权码配置到 `my-app-backend/.env` 文件中：

```env
MAIL_HOST=smtp.qq.com
MAIL_PORT=465
MAIL_USER=你的QQ邮箱@qq.com
MAIL_PASSWORD=你刚才复制的授权码
# MAIL_FROM 可选：如果不设置，会自动使用 MAIL_USER 作为发件人
# ⚠️ 重要：如果设置了 MAIL_FROM，其中的邮箱地址必须与 MAIL_USER 完全一致！
MAIL_FROM="Tomato Calendar" <你的QQ邮箱@qq.com>
```

**重要提示**：
- `MAIL_USER` 填写完整的QQ邮箱地址，例如：`1227533922@qq.com`
- `MAIL_PASSWORD` 填写**授权码**，不是QQ登录密码！
- `MAIL_FROM` 中的邮箱地址必须与 `MAIL_USER` **完全一致**（例如都是 `1227533922@qq.com`）
- 如果不设置 `MAIL_FROM`，系统会自动使用 `MAIL_USER` 作为发件人
- 授权码只显示一次，如果忘记了需要重新生成

### 步骤7: 重启服务

配置完成后，重启后端服务：

```bash
npm run start:dev
```

## 常见问题

### Q: 授权码忘记了怎么办？
A: 需要重新生成。重复上述步骤，系统会生成新的授权码，旧的授权码会失效。

### Q: 可以同时有多个授权码吗？
A: 可以，但建议只保留必要的授权码，不需要的可以关闭对应的服务。

### Q: 授权码和登录密码有什么区别？
A: 
- **登录密码**：用于登录QQ邮箱网页版和QQ客户端
- **授权码**：专门用于第三方应用（如本应用）通过SMTP发送邮件，更安全

### Q: 授权码泄露了怎么办？
A: 立即关闭SMTP服务，然后重新开启生成新的授权码。

## 注意事项

1. ✅ 授权码只显示一次，请立即保存
2. ✅ 不要将授权码分享给他人
3. ✅ 定期更换授权码以提高安全性
4. ✅ 如果授权码失效，检查是否在邮箱中关闭了SMTP服务
