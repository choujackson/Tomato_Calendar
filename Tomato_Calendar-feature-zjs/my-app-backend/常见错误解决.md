# 🔧 常见错误解决方案

## 1. 535 Error: authentication failed

**错误信息**：`535 Error: authentication failed`

**原因**：SMTP认证失败，通常是使用了QQ登录密码而不是授权码。

**解决方法**：
1. 确保使用**授权码**而不是QQ登录密码
2. 参考 `QQ邮箱授权码获取教程.md` 获取授权码
3. 在 `.env` 文件中将 `MAIL_PASSWORD` 设置为授权码

---

## 2. 553 Mail from must equal authorized user

**错误信息**：`553 Mail from must equal authorized user`

**原因**：发件人地址（MAIL_FROM中的邮箱）与认证用户（MAIL_USER）不一致。

**解决方法**：

**方法1（推荐）**：删除 `MAIL_FROM` 配置，系统会自动使用 `MAIL_USER` 作为发件人：

```env
MAIL_HOST=smtp.qq.com
MAIL_PORT=465
MAIL_USER=1227533922@qq.com
MAIL_PASSWORD=your_auth_code
# 不设置 MAIL_FROM，系统会自动使用 MAIL_USER
```

**方法2**：确保 `MAIL_FROM` 中的邮箱地址与 `MAIL_USER` 完全一致：

```env
MAIL_HOST=smtp.qq.com
MAIL_PORT=465
MAIL_USER=1227533922@qq.com
MAIL_PASSWORD=your_auth_code
# ⚠️ 邮箱地址必须与 MAIL_USER 一致
MAIL_FROM="Tomato Calendar" <1227533922@qq.com>
```

**注意**：
- `MAIL_USER=1227533922@qq.com`
- `MAIL_FROM` 中的邮箱也必须是 `1227533922@qq.com`
- 不能使用不同的邮箱地址

---

## 3. 无法连接到SMTP服务器

**错误信息**：`ECONNREFUSED` 或连接超时

**原因**：
- 网络连接问题
- 端口被防火墙阻止
- SMTP服务器地址错误

**解决方法**：
1. 检查网络连接
2. 检查防火墙设置，确保允许465端口
3. 确认SMTP服务器地址正确（QQ邮箱：`smtp.qq.com`）
4. 尝试使用587端口（需要修改 `secure: false`）

---

## 4. 邮件发送成功但收不到邮件

**可能原因**：
1. 邮件被放入垃圾箱/ spam 文件夹
2. 收件人邮箱地址错误
3. 邮件服务商限制

**解决方法**：
1. 检查收件箱的垃圾邮件文件夹
2. 确认收件人邮箱地址正确
3. 检查发件人邮箱是否被标记为垃圾邮件

---

## 快速检查清单

遇到邮件发送问题时，请按以下顺序检查：

- [ ] `MAIL_USER` 是否填写了完整的邮箱地址？
- [ ] `MAIL_PASSWORD` 是否使用了授权码（不是登录密码）？
- [ ] `MAIL_FROM` 中的邮箱地址是否与 `MAIL_USER` 一致？
- [ ] SMTP服务是否已开启（QQ邮箱需要开启POP3/SMTP服务）？
- [ ] 授权码是否有效（是否过期或被重新生成）？
- [ ] 网络连接是否正常？
- [ ] 防火墙是否允许465端口？
