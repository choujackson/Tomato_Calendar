# 📧 邮件发送问题排查指南

## 问题：注册时验证码发送失败

如果遇到"邮件发送失败，请稍后重试"的错误，请按以下步骤排查：

## 第一步：检查后端终端错误日志

查看后端运行终端的详细错误信息，常见错误包括：

### 1. `535 Error: authentication failed`
**原因**：SMTP认证失败  
**解决方法**：
- 检查 `MAIL_PASSWORD` 是否使用了**授权码**而不是登录密码
- 参考 `QQ邮箱授权码获取教程.md` 获取授权码
- 确保授权码未过期

### 2. `553 Mail from must equal authorized user`
**原因**：发件人地址与认证用户不一致  
**解决方法**：
- 代码已自动处理，确保 `MAIL_FROM` 和 `MAIL_USER` 的邮箱地址一致
- 如果不设置 `MAIL_FROM`，系统会自动使用 `MAIL_USER` 作为发件人

### 3. `ECONNREFUSED` 或连接超时
**原因**：无法连接到SMTP服务器  
**解决方法**：
- 检查网络连接
- 检查防火墙是否阻止了465端口
- 确认SMTP服务器地址正确（QQ邮箱：`smtp.qq.com`）

## 第二步：检查 .env 配置文件

确保在 `my-app-backend` 目录下有 `.env` 文件，并正确配置：

```env
# QQ邮箱配置示例
MAIL_HOST=smtp.qq.com
MAIL_PORT=465
MAIL_USER=你的QQ邮箱@qq.com
MAIL_PASSWORD=你的授权码（不是登录密码）
# MAIL_FROM 可选，不设置会自动使用 MAIL_USER
```

**重要检查项**：
- ✅ `MAIL_USER` 填写了完整的邮箱地址（例如：`1227533922@qq.com`）
- ✅ `MAIL_PASSWORD` 填写的是**授权码**，不是QQ登录密码
- ✅ 授权码已从QQ邮箱获取并正确配置

## 第三步：验证邮箱配置

1. **确认SMTP服务已开启**：
   - 登录 QQ 邮箱网页版
   - 设置 → 账户 → 查看 "POP3/SMTP服务" 是否已开启

2. **确认授权码有效**：
   - 授权码只显示一次
   - 如果忘记了，需要重新生成
   - 重新生成后，旧的授权码会失效，需要更新 `.env` 文件

## 第四步：重启后端服务

修改 `.env` 配置后，**必须重启后端服务**才能生效：

```bash
# 停止当前服务（Ctrl+C）
# 然后重新启动
cd my-app-backend
npm run start:dev
```

## 第五步：查看详细错误日志

代码已更新，现在会输出更详细的错误信息。查看后端终端，会显示：
- 错误代码（如 EAUTH, EENVELOPE）
- 错误消息
- 响应代码和命令

根据这些信息可以更精确地定位问题。

## 快速检查清单

遇到邮件发送失败时，按以下顺序检查：

- [ ] 查看后端终端是否有错误日志
- [ ] `.env` 文件是否存在且配置正确
- [ ] `MAIL_PASSWORD` 是否使用了授权码（不是登录密码）
- [ ] QQ邮箱SMTP服务是否已开启
- [ ] 授权码是否有效（未过期）
- [ ] 修改配置后是否重启了后端服务
- [ ] 网络连接是否正常
- [ ] 防火墙是否允许465端口

## 测试步骤

1. 确保后端服务正在运行
2. 使用 Postman 或前端应用测试 `/users/send-code` 接口
3. 查看后端终端的错误日志（如果有）
4. 检查收件箱（包括垃圾邮件文件夹）

2. `.env` 文件配置（隐藏敏感信息）
