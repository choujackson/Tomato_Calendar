# 📧 邮件服务配置说明

## 问题描述

如果遇到 `535 Error: authentication failed` 错误，说明 SMTP 认证失败，通常是邮箱配置问题。

## 解决方案

### QQ邮箱配置

1. **开启SMTP服务**
   - 登录 QQ 邮箱网页版
   - 设置 → 账户 → 开启 SMTP 服务
   - 生成授权码（不是登录密码！）

2. **配置环境变量 (.env 文件)**

在 `my-app-backend` 目录下创建或编辑 `.env` 文件：

```env
# QQ邮箱SMTP配置
MAIL_HOST=smtp.qq.com
MAIL_PORT=465
MAIL_USER=你的QQ邮箱@qq.com
MAIL_PASSWORD=你的授权码（不是登录密码）
# MAIL_FROM 可选：如果不设置，会自动使用 MAIL_USER 作为发件人
MAIL_FROM="Tomato Calendar" <你的QQ邮箱@qq.com>
```

**重要提示**：
- `MAIL_USER`: 填写完整的QQ邮箱地址（例如：`1227533922@qq.com`）
- `MAIL_PASSWORD`: 填写**授权码**，不是QQ登录密码！
- `MAIL_FROM`: 发件人信息（可选）
  - ⚠️ **如果设置了MAIL_FROM，其中的邮箱地址必须与MAIL_USER完全一致！**
  - 如果不设置MAIL_FROM，系统会自动使用MAIL_USER作为发件人地址

### 常见问题

#### Q: 为什么使用授权码而不是密码？
A: 为了安全考虑，大多数邮箱服务商要求使用授权码而不是登录密码来通过SMTP发送邮件。

#### Q: 如何获取QQ邮箱授权码？
A: 
1. 登录 QQ 邮箱网页版
2. 点击"设置" → "账户"
3. 找到"POP3/IMAP/SMTP/Exchange/CardDAV/CalDAV服务"
4. 开启"POP3/SMTP服务"或"IMAP/SMTP服务"
5. 点击"生成授权码"
6. 按提示发送短信验证
7. 复制生成的授权码

#### Q: 为什么出现 "553 Mail from must equal authorized user" 错误？
A: 这个错误表示发件人地址（MAIL_FROM中的邮箱）必须与认证用户（MAIL_USER）完全一致。

**解决方法**：
- 确保 `MAIL_FROM` 中的邮箱地址与 `MAIL_USER` 完全相同
- 或者删除 `MAIL_FROM` 配置，系统会自动使用 `MAIL_USER` 作为发件人

例如，如果 `MAIL_USER=1227533922@qq.com`，那么 `MAIL_FROM` 也必须是 `1227533922@qq.com`：
```env
MAIL_USER=1227533922@qq.com
MAIL_FROM="Tomato Calendar" <1227533922@qq.com>  # 邮箱地址必须一致
```

#### Q: 端口 465 和 587 有什么区别？
A: 
- **465**: 使用 SSL/TLS 加密，`secure: true`
- **587**: 使用 STARTTLS，`secure: false`

当前配置使用 465 端口，`secure: true`。

#### Q: 如何切换端口？
如果 465 端口不可用，可以尝试 587 端口，需要修改：

1. `.env` 文件：
```env
MAIL_PORT=587
```

2. `src/app.module.ts`：
```typescript
secure: false, // 587端口使用false
```
